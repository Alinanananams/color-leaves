# Color Leaves

C#-плагин для **Autodesk Revit 2021**: панель стадий готовности листов с цветовой подсветкой, фильтрами и группировкой.

Плагин добавляет на ленту Revit вкладку **«Цветные листики»** и докируемую панель со всеми листами проекта.

## Возможности

- 📋 **Таблица всех листов проекта**: номер, наименование, стадия готовности
- 🎨 **Цветовая подсветка строк** по стадии (Черновик → На проверке → Проверен → Утверждён → Выпущен и т.д.), цвета настраиваются
- ✏️ **Смена стадии прямо в таблице** — значение записывается в параметр листа «Стадия готовности»
- 🔍 **Фильтры**: поиск по номеру/имени/стадии + фильтр по стадии
- 🗂 **Группировка по стадиям** с подсчётом листов в каждой группе
- ↗️ **Переход к листу** — двойной клик по строке открывает лист в Revit
- ⚙️ **Автосоздание параметра** «Стадия готовности» (экземпляр, текст) и автозаполнение стадий по данным листа
- 👥 **Работа в общих моделях**: видно, кто держит лист; занятые листы защищены от записи; массовые операции пропускают чужие листы с отчётом
- 📝 **Лог работы**: `%APPDATA%\Autodesk\Revit\ColorSheets\log.txt`

## Требования

- Autodesk Revit **2021**
- Windows 10/11 x64
- [.NET SDK 8.0](https://dotnet.microsoft.com/download) — только для сборки из исходников

## Установка

**Способ 1 — инсталлятор (рекомендуется):**

Скачайте `ColorLeaves-<версия>-setup.exe` со страницы [Releases](https://github.com/Alinanananams/color-leaves/releases), запустите и нажмите «Установить». Все файлы плагина зашиты в установщик и копируются в `%APPDATA%\Autodesk\Revit\Addins\2021\`.

**Способ 2 — zip вручную:**

Скачайте `ColorLeaves-R21.zip` со страницы [Releases](https://github.com/Alinanananams/color-leaves/releases) и распакуйте содержимое в `%APPDATA%\Autodesk\Revit\Addins\2021\`.

**Способ 3 — обновление из Revit:**

Если плагин уже установлен (v1.2.0 и новее) — вкладка «Цветные листики» → кнопка **«Обновления»**: плагин проверит последнюю версию на GitHub, скачает и применит обновление после закрытия Revit.

**Способ 4 — из исходников:**

```sh
git clone https://github.com/Alinanananams/color-leaves.git
cd color-leaves
build-and-deploy.bat
```

## Сборка

Плагин ссылается на Revit API через NuGet-пакеты [`Nice3point.Revit.Api.*`](https://www.nuget.org/packages/Nice3point.Revit.Api), поэтому локально установленный Revit для сборки **не требуется**.

```sh
dotnet build build/ColorLeaves.sln -c Release
```

Быстрая сборка и установка в Revit: `build-and-deploy.bat`.
Сборка установщика: `tools/build-installer.bat`.

## Отладка

1. Выполните `build-and-deploy.bat`
2. Запустите Revit 2021 и откройте панель плагина
3. В Visual Studio: **Debug → Attach to Process → `Revit.exe`**

Лог: `%APPDATA%\Autodesk\Revit\ColorSheets\log.txt`.

## Структура проекта

```
color-leaves
├── src/
│   ├── ColorLeaves.Core/        # Модели, чтение листов, стадии, параметры
│   └── ColorLeaves.Revit/       # Точка входа, Bridge, команды, UI (WinForms)
├── build/ColorLeaves.sln        # Решение Visual Studio
├── addins/2021/                 # Манифест .addin для Revit 2021
├── tools/installer/             # Исходник установщика (exe)
├── DOCS/                        # Планы фич
├── AGENTS.md                    # Инструкции для AI-ассистентов
├── build-and-deploy.bat         # Сборка и установка в Revit
└── Version.txt                  # Версия плагина (единый источник)
```

## Важно

- `RevitAPI.dll` и `RevitAPIUI.dll` не входят в репозиторий — приходят через NuGet
- Для коммерческого использования замените `VendorId` в `addins/2021/ColorLeaves.addin`
- `AddInId` задан уникальным GUID. При конфликте с другим плагином замените его
